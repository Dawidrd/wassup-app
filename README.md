# Wassup – suplementy, które rozumiesz

Wersja testowa (PWA): tracker magnezu, witaminy D i B6 na tle progów z etykiety (RWS), norm żywienia (NIZP PZH 2024), limitów Zespołu ds. Suplementów Diety GIS i górnych poziomów spożycia (UL).

- Działa w przeglądarce i po dodaniu do ekranu głównego iPhone'a (Safari → Udostępnij → Do ekranu początkowego).
- Dane zapisują się wyłącznie lokalnie na urządzeniu. Repozytorium zawiera tylko kod.
- Wassup informuje i liczy, ale nie zaleca dawek ani nie zastępuje porady lekarza lub farmaceuty.
